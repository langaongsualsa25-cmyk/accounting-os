# เทียบแผน Automation (27.10.2026) กับพิมพ์เขียว Accounting OS

ต้นฉบับ: [automation-plan-2026-10-27.md](automation-plan-2026-10-27.md) (แปลงจาก .docx ที่ Phong อัปโหลด)

## สรุปสั้น
"สิ่งที่อยากให้ระบบทำ" ในแผนนี้ส่วนใหญ่เข้ากับพิมพ์เขียวได้ และบางส่วนเราสร้างไปแล้ว เช่น Audit, การตรวจสองชั้น และสิทธิ์ผู้ใช้
ส่วนที่ขัดกันคือ **"เครื่องมือที่ใช้"** แผนนี้วางระบบบน Google (Sheets, Drive, Apps Script, AppSheet, Vision/Document AI, Looker Studio), LINE และ FlowAccount API
ข้อมูลลูกค้าจึงต้องออกไปอยู่บน Cloud ภายนอก ซึ่งขัดกับพิมพ์เขียวส่วนที่ 1 (On-Premise ห้ามส่งข้อมูลไป External AI/API) และกฎโปรเจกต์ข้อ 4

## สิ่งที่จะเปลี่ยนในแผน (ถ้า Phong เห็นด้วย)
1. **PR 5** เพิ่ม "เอกสารที่ต้องส่งประจำเดือนต่อบริษัท" + สถานะ ครบ / ไม่ครบ / ต้องแก้ + โครงจัดเก็บ บริษัท/เดือน/ประเภท
2. **PR 6** แจ้งเตือนภายในเรื่องเอกสารค้างตามปฏิทิน (ยังไม่ส่งออกนอกระบบ)
3. **PR 8** หน้าอัปโหลดตรวจภาพชัดด้วย Tesseract.js บนเบราว์เซอร์
4. **เฟส 2** เพิ่ม: Portal ลูกค้า, นำเข้า Statement + Auto-matching, ข้อความเตือนลูกค้า (ไม่มีข้อมูลลับ)
5. **เฟส 3** OCR + จัดหมวดค่าใช้จ่าย ด้วยเครื่องมือภายใน พร้อมฟอร์มตรวจก่อนบันทึก
